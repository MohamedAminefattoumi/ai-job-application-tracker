AI Job Application Tracker — Frontend

This archive contains the Vanilla HTML/CSS/JavaScript frontend based on the previous JobTrack frontend archive.

Run locally:
1. Extract the frontend folder into your project.
2. Start FastAPI on http://localhost:8000.
3. Open index.html with VS Code Live Server (recommended).

API base URL is configured in assets/js/api.js.
The dashboard's Sync inbox button calls POST /applications/sync.
No React, Vite, npm, Supabase, or Firebase is used.

Design direction: warm editorial palette — ivory, forest green, muted terracotta and ochre; no purple gradient dashboard styling.
